# Code of conduct

Unbox Box is a friendly place to talk about Formula 1 and code.

- Be respectful and assume good intent. Critique ideas and code, never people.
- No harassment, insults, or discrimination of any kind, including about the drivers, teams
  and fans we write about.
- Help newcomers; everyone started somewhere.
- Keep discussion on topic and in good faith.

Maintainers may edit or remove comments, issues or pull requests that break these rules, and
may block people who keep breaking them. Report problems privately through GitHub (Security →
Report a vulnerability is fine for anything sensitive) or by contacting a maintainer.
